# 🎀 Mochi Vocab Quest — เกม Quiz คำศัพท์จิบิ 280 คำ

เกมส์ Quiz ทายความหมายภาษาไทยที่ถูกต้อง (ตัวเลือก `a b c d`) ครบทั้ง **280 คำศัพท์** (`bed` → `complicated`, ระดับ `A1`–`B2`) ออกแบบสไตล์จิบิน่ารัก รองรับการเปิดใช้งานแบบ **เต็มจอ 100% บน iPad**

## 📱 วิธีเปิดแบบเต็มจอบน iPad
1. เปิดลิงค์ GitHub Pages ด้วย **Safari** บน iPad
2. แตะปุ่ม **แชร์ (⬆️)** → เลือก **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**
3. เปิดเกมจากไอคอน **Chibi Vocab** บนหน้าจอโฮมเพื่อใช้งานแบบเต็มจอ!
